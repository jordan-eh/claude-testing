# claude-testing

**Debrief — "Does this need to be a meeting?"** A single-page brand site for a tool that scores meeting invites and tells you whether to send an email instead.

## Preview it

Everything (HTML + CSS) lives in `index.html`; fonts load from Google Fonts. No build step.

- **Quickest:** double-click `index.html` to open it in your browser.
- **Local server:**
  ```bash
  python3 -m http.server 8000
  ```
  then open http://localhost:8000

## Files

| File | What it is |
|---|---|
| `index.html` | The page — markup and all styles inline |
| `PRODUCT.md` | Product purpose, users, brand personality |
| `DESIGN.md` | Design system: color, type, spacing, components |
| `CLAUDE.md` | Project instructions for Claude |
| `plan.md` | Build plan |
| `AUDIT-REMEDIATION.md` | Accessibility/design audit fixes |
